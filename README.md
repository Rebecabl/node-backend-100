# Node | Backend | 100 Projects

Este repositório reúne **100 mini projetos backend** desenvolvidos com **Node.js**.

Cada pasta representa **um projeto independente**, criado com o objetivo de praticar
fundamentos de backend, APIs, serviços, regras de negócio e boas práticas de organização
de código.

---

## Objetivo do Repositório

O foco deste repositório é a evolução prática no desenvolvimento backend, partindo de
projetos simples até soluções um pouco mais completas, simulando cenários reais do
dia a dia de um desenvolvedor.

Os projetos abordam conceitos como:
- Criação de APIs e serviços backend  
- Estruturação de projetos  
- Manipulação de dados  
- Regras de negócio  
- Boas práticas de código  
- Organização e versionamento com Git
