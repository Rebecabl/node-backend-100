# Day 10 — Environment Config Loader

Este projeto faz parte do repositório **Node | Backend | 100 Projects**.

O objetivo é aprender a configurar uma aplicação backend usando
variáveis de ambiente.

---

## O que são variáveis de ambiente

Variáveis de ambiente são valores externos ao código que controlam
o comportamento da aplicação.

Exemplos:
- porta do servidor
- ambiente (development, production)
- nome da aplicação
- credenciais (em projetos reais)

---

## Por que isso é importante

Sem variáveis de ambiente:
- você precisa mudar o código para cada ambiente
- o código fica inseguro
- não funciona bem em produção

Com variáveis de ambiente:
- o mesmo código roda em qualquer lugar
- configuração fica separada da lógica
- padrão profissional de mercado
